To create a new quotation in MAQSU ERP, follow these steps:

**1️⃣ Go to the Creation Page**

From the main dashboard, navigate to: **Sales** → **Quotations**

Then click the “**Create**” button at the top-left.

![](/img/sales/create_quotation_01.png)

**2️⃣ Fill in the Customer name**

![](/img/sales/create_quotation_02.png)

In the **Customer** field, start typing the customer's name. Select the correct customer from the dropdown list.

**3️⃣ Fill in Quoatation Details**

In the quotation form, fill out the following:

* **Doc. No:** Auto-generated document number.
* **Expiration:** Set the quotation's expiration date.
* **Quotation Date:** Set the date of the quotation.
* **Payment Terms:** Select payment terms if applicable.

![](/img/sales/create_quotation_03.png)

**4️⃣ Add Products/Services**

Under the **Order Lines** section, click **Add a Product**.

![](/img/sales/create_quotation_04.jpg)

* **Discount:** Apply any discounts if necessary.(Optional)
* **Add Multi-Products:** Click to add multiple products at once.(Optional)

**5️⃣ Save the Quotation**

Once all details are filled in, click the “**Save**” button at the top-left to save the quotation.
