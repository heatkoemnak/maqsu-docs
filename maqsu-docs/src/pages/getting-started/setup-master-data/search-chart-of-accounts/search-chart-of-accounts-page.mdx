Here’s how you can search for a **Chart of Account (COA)** in **MAQSU ERP** — step by step

![](/img/getting-started/chart-of-accounts/setup-chart-of-accounts_04.png)

You can search by:

**Account Code** → e.g., 102001

**Account Name** → e.g., Cash

**Account Type** → e.g., Bank and Cash

**Account Group** → e.g., Receivable

**Tags** → e.g., Current Asset

Example:
If you type **Cash** → MAQSU will display all accounts that contain “**Cash**” in the name or tag (like “Cash on Hand” or “Cash at Bank”).
