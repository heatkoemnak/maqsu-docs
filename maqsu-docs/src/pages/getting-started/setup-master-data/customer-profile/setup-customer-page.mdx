This guide explains how to fill in each field in the **Customer Creation** form in MAQSU ERP, as shown on the “Customers / \[Customer Name]” page. It helps users enter customer details correctly in both English (Latin) and Khmer formats.

**1️⃣ Go to the Customer Menu**

From the main dashboard, navigate to: **Accounting** → **Customers** → **Customers**

![](/img/getting-started/customers/create_customer_01.png)

**2️⃣ Create a New Customer**

Click the “**Create**” button.

![](/img/getting-started/customers/create_customer_02.png)

**3️⃣ Fill in Customer Details**

Fill out the following fields as needed:

1\. Customer Name

![](/img/getting-started/customers/create_customer_03.png)

* **Individual:** For a single person or end-user customer.
* **Company:** For a registered business or shop.

✅ Check the **Customer** box if this record represents a buyer.\
✅ Check **Vendor** if the same record will be used for purchases.

2\.  Contact & Address

![](/img/getting-started/customers/create_customer_04.png)

3\. Save the Customer

Click **Save** once all information is entered.
