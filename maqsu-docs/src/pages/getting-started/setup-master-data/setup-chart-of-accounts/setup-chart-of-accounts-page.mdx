Setting up a **Chart of Accounts (COA)** in **MAQSU ERP** is an important first step before you start recording any accounting transactions.

Here’s a clear step-by-step guide to help you set it up properly

**1️⃣ Go to Chart of Accounts**

From the main dashboard, navigate to: **Accounting** → **Configuration** → **Chart of Accounts**

![](/img/getting-started/chart-of-accounts/setup-chart-of-accounts.png)

This page lists all existing accounts already created by default (Assets, Liabilities, Income, Expenses, etc.).

**2️⃣ Create a New Account**

Click the “**Create**” button.

You’ll see a form with several fields.

![](/img/getting-started/chart-of-accounts/setup-chart-of-accounts_02.png)

**3️⃣ Fill in Account Details**

![](/img/getting-started/chart-of-accounts/setup-chart-of-accounts_03.png)

1. **Account Code:** The numeric code that identifies the account.
2. **Name:** The descriptive name of the account.
3. **Type:** Defines how the account behaves in the system and in reports (Balance Sheet, Profit & Loss, etc.).
4. **Default Taxes:** Usually left empty for cash accounts. Used for accounts that automatically apply certain taxes (e.g., VAT 10%) on transactions.
5. **Tags:** Optional labels used for filtering or grouping in reports (for example: “Current Asset”, “Liquidity”).
6. **Account Group:** The higher-level grouping or category for reporting (like a parent folder).
7. **Inactive:** When checked, the account is disabled (not used anymore). Leave unchecked if active.
